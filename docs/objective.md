## 왜 목적함수가 의도언어인가

같은 필지, 같은 규제, 같은 코어 타입에서도 설계사무소마다 다른 답이 나온다.
검증 8필지(화곡 alt1/2/3 = 동일 필지의 세 정답)가 그 증거:

| 케이스 | GT 주차 | 법정대수 | 읽히는 의도 |
|---|---|---|---|
| 화곡 alt1 | **7대** | 6대 | 법정 초과 — 주차대수 자체가 가치 (`parking`) |
| 화곡 alt2 | 6대 | 6대 | 법정만 충족, 나머지는 평면 정형성 (`units`) |
| 화곡 alt3 | **5대** | 6대 | 주차를 덜고 마당을 남김 (`yard`) |

배치를 가르는 건 기하 조건이 아니라 **무엇을 더 좋다고 보느냐** — 즉 목적함수다.
그래서 objective는 BuildOptions(설계 의도언어)의 1급 시민이다.

## 3층 의도언어에서의 위치

```
derive (기계)       : 법정주차대수, 코어 치수, 차로 폭 — 엔진이 계산. 옵션 아님.
parameterize (의도)  : core_type, units_by_level, structure — 이산 선택.
objective (목적함수) : ["parking", "walk", ...] — 후보 배치안 랭킹 우선순위. ★이 문서
```

엔진은 **생성기⟂선택기**:
1. 생성기 — 코어 위치×주차 패턴 후보를 전수 생성 (oracle, Coverage 담당)
2. 선택기 — objective 우선순위로 후보를 랭킹해 primary 1개 채택 (Soundness 담당)

## 형식: 우선순위 리스트 (lexicographic)

```json
{ "objective": ["parking", "units"] }
```

1순위 criterion으로 비교 → 동률이면 2순위 → … → 최종 tie-break는 엔진 prior.

**가중치(weights)가 아닌 이유**: float 가중합은 설계 언어가 아니라 튜닝 파라미터다.
건축가는 "주차 먼저, 그다음 동선"이라고 말하지 "주차 0.7 + 동선 0.3"이라고 말하지 않는다.
우선순위 리스트는 LLM이 자연어에서 직접 변환할 수 있는 어휘이기도 하다.

## Criterion 어휘 (v1)

| criterion | 의미 | 엔진 계산 |
|---|---|---|
| `parking` | 주차대수 — 법정 초과도 가치 | stall 수 `n` |
| `walk` | 도로→코어 보행 최단 | `-distance(core, 도로)` |
| `units` | 세대분할 정형성 — 예쁜 직사각형 N개 | division score `J` |
| `yard` | 잔여 마당 정형성 | `(lot−core−stalls)의 면적/MRR면적` |

### 어휘에 없는 것 (의도적 제외)

- **법정주차 충족** — 어휘가 아니라 **0순위 고정**(derive층). `min(n, 법정)/법정` 포화 비교를
  항상 먼저 적용한다. objective로 법규를 끌 수는 없다.
- **연접(주차 묶음)** — 주차장법 11조5항을 placer가 이미 강제. 선호가 아닌 제약.
- **rear(코어 후면 배치)** — walk의 반대 의도. 8필지 GT에 증거 없음(가중치 +0.15 실험이
  성내 회귀 유발) → 확장 원칙 ①(GT 증거) 미충족으로 보류.

### attach(코어 외벽 밀착)가 들어왔다 빠진 경위 (사례)

attach는 "BIM 변-공유 제약"→"criterion"으로 한 번 편입됐다가(합성식 J에서 edge항 제거 시
삼전 코어 54→5% 붕괴 증거) 최종 제외됐다 — **생성기가 magnet 앵커(4코너+4변중점)로
코너 밀착을 구조적으로 보장**하므로, 모든 후보가 이미 밀착돼 있어 선택 criterion으로서
변별력이 없다. 교훈: 어떤 '좋음'은 선택이 아니라 **생성의 형태**로 넣는 게 맞다.

### 확장 원칙

새 criterion은 ① GT에서 의도 차이로 읽히는 증거가 있고 ② 엔진이 후보별로 계산 가능하고
③ 기존 어휘로 표현 불가할 때만 추가한다. 후보: `daylight`(채광), `privacy`(간섭 최소),
`cost`(공사비). 어휘는 작게 — 늘리기 전에 정말 필요한지 의심할 것.

## 기본값

`objective: []` (빈 리스트) = 엔진 prior: **법정주차 충족(포화) → 세대분할 J**.
options 없이도 엔진은 항상 동작한다 (graceful default).

## 평가 프로토콜

- **Coverage**: GT가 후보 oracle 안에 있는가 — `max over K` IoU. 생성기의 책임.
- **Soundness**: objective(+parameterize)를 알 때 primary가 GT를 재현하는가 — primary IoU.
  선택기의 책임. 이 문서의 어휘가 맞다면, GT별 objective 기입 후 Soundness가 Coverage에 수렴해야 한다.
