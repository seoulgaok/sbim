seoulgaok-bim-core
==================

sbim의 Python 패키지 — `scheme.json`·`units.json`의 pydantic 타입(정본), io, 설계 옵션
`BuildOptions`, 설정 오버레이, IFC 내보내기·되읽기.

```bash
pip install -e "./python[ifc]"     # IFC 불필요하면 ./python
```

설명 전체는 저장소 루트의 [README](../README.md)에 있다. 이 파일은 그 사본이 아니라
패키지 메타데이터용 짧은 안내다.
